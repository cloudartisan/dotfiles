# General Instructions

## Commits
- Do not attribute commits or PRs to an agentic tool: no co-author trailer,
  no "with Claude's help", no "generated by". I switch tools freely. Naming a
  tool is fine when the change is specific to it, e.g. a fix to `.claude/`
  that doesn't apply to `.codex/`.
- No emojis in commit messages.

## Code
- Blank lines never carry whitespace or indentation unless the file format
  requires it.

## Language
- UK English, unless a project's own instructions say otherwise.
- No em dashes or en dashes as punctuation: use full stops, commas, colons
  or parentheses. Hyphens in compound words and code are fine.
